@minutes 12
Q: If $a - b = 2$ and $ab = 15$, then $a^2 + b^2 =$
- 19
- 30
* 34
- 40
W: $a^2 + b^2 = (a - b)^2 + 2ab = 4 + 30 = 34$.

Q: The value of $101^3$ is
- 1 003 001
* 1 030 301
- 1 303 001
- 1 030 101
W: $(100 + 1)^3 = 1\,000\,000 + 30\,000 + 300 + 1 = 1\,030\,301$.

Q: Factorising $x^3 - 8$ gives
- $(x - 2)(x^2 - 2x + 4)$
* $(x - 2)(x^2 + 2x + 4)$
- $(x + 2)(x^2 - 2x + 4)$
- $(x - 2)^3$
W: $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$ with $a = x$ and $b = 2$.

Q: If $x + \dfrac{1}{x} = 2$, then $x^2 + \dfrac{1}{x^2} =$
- 0
- 1
* 2
- 4
W: $4 - 2 = 2$.

Q: If $a + b = 9$ and $a - b = 3$, then $a^2 - b^2 =$
- 6
- 12
* 27
- 81
W: $a^2 - b^2 = (a + b)(a - b) = 27$.

Q: $(x + y)^2 - (x - y)^2 =$
- $2xy$
* $4xy$
- $2x^2 + 2y^2$
- 0
W: $(x^2 + 2xy + y^2) - (x^2 - 2xy + y^2) = 4xy$.

Q: The value of $99^2$ is
- 9601
- 9701
* 9801
- 9901
W: $(100 - 1)^2 = 10\,000 - 200 + 1 = 9801$.

Q: If $a + b + c = 0$, then $a^3 + b^3 + c^3 =$
- 0
- $abc$
* $3abc$
- $a + b + c$
W: When $a + b + c = 0$, $a^3 + b^3 + c^3 = 3abc$.
