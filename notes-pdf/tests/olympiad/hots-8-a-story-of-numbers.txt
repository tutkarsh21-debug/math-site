Q: The number 1011 in base 2 equals which number in base 10?
- 9
- 10
* 11
- 13
W: $8 + 0 + 2 + 1 = 11$.

Q: The number 25 in base 2 is
- 10101
- 11000
* 11001
- 11011
W: $25 = 16 + 8 + 1$, so the digits are 1 1 0 0 1.

Q: The value of $213_4$ in base 10 is
- 25
- 31
* 39
- 45
W: $2 \times 16 + 1 \times 4 + 3 = 39$.

Q: In the Indian system the number 3,52,000 is written. The digit 5 stands for
- 5000
* 50 000
- 5 00 000
- 500
W: The groups are 3 lakh, 52 thousand, so the 5 is in the ten-thousands place and stands for 50 000.

Q: The largest digit used in base 5 is
- 3
* 4
- 5
- 6
W: In base $b$ the digits are $0$ to $b - 1$.

Q: How many different numbers can be written with 3 binary digits (leading zeros allowed)?
- 3
- 6
* 8
- 9
W: Each of the 3 places has 2 choices, so $2^3 = 8$.

Q: In base 2, $11 + 1$ equals
- 10
* 100
- 110
- 12
W: $3 + 1 = 4$, which is $100_2$.

Q: Without zero as a placeholder, which problem would occur?
* 105 and 15 would look the same
- Numbers would be smaller
- Addition would be impossible
- Only odd numbers could be written
W: Zero holds an empty place. Without it, 105 would be written 1 5, the same as 15.
