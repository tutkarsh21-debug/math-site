# Solved HOTS questions
- A rational number can be written $\dfrac{p}{q}$ with $q \ne 0$, and its decimal terminates or repeats. An irrational number has a decimal that neither terminates nor repeats. To rationalise $\dfrac{1}{a + \sqrt{b}}$, multiply the top and bottom by $a - \sqrt{b}$, since $(a + \sqrt{b})(a - \sqrt{b}) = a^2 - b$.
?eg Express $0.\overline{27}$ (that is 0.272727...) in the form $\dfrac{p}{q}$.
= Let $x = 0.272727\ldots$. Then $100x = 27.272727\ldots$.
= Subtracting: $99x = 27$, so $x = \dfrac{27}{99}$.
=> $\dfrac{3}{11}$
?eg Find three rational numbers between $\dfrac{1}{3}$ and $\dfrac{1}{2}$.
= Write both with the same denominator: $\dfrac{1}{3} = \dfrac{8}{24}$ and $\dfrac{1}{2} = \dfrac{12}{24}$.
= The fractions $\dfrac{9}{24}$, $\dfrac{10}{24}$ and $\dfrac{11}{24}$ lie between them.
=> $\dfrac{3}{8}$, $\dfrac{5}{12}$ and $\dfrac{11}{24}$
?eg Rationalise the denominator of $\dfrac{1}{\sqrt{5} - \sqrt{3}}$.
= Multiply the top and bottom by $\sqrt{5} + \sqrt{3}$: the denominator becomes $5 - 3 = 2$.
=> $\dfrac{\sqrt{5} + \sqrt{3}}{2}$
?eg If $x = 2 + \sqrt{3}$, find $x + \dfrac{1}{x}$ and $x^2 + \dfrac{1}{x^2}$.
= $\dfrac{1}{x} = \dfrac{1}{2 + \sqrt{3}} \times \dfrac{2 - \sqrt{3}}{2 - \sqrt{3}} = 2 - \sqrt{3}$.
= $x + \dfrac{1}{x} = 4$, and $x^2 + \dfrac{1}{x^2} = 4^2 - 2$.
=> 4 and 14
?eg Given that $\sqrt{5}$ is irrational, show that $3 + 2\sqrt{5}$ is irrational.
= Suppose $3 + 2\sqrt{5} = r$ is rational. Then $\sqrt{5} = \dfrac{r - 3}{2}$, which is rational.
= This contradicts the fact that $\sqrt{5}$ is irrational.
=> $3 + 2\sqrt{5}$ is irrational

Q: Express $0.\overline{6}$ (0.666...) as a fraction.
A: $\dfrac{2}{3}$.

Q: Express $0.\overline{14}$ (0.141414...) as a fraction.
A: $\dfrac{14}{99}$.

Q: Find three rational numbers between $\dfrac{1}{4}$ and $\dfrac{1}{3}$.
A: For example $\dfrac{4}{15}$, $\dfrac{17}{60}$ and $\dfrac{3}{10}$.

Q: Rationalise the denominator of $\dfrac{1}{\sqrt{7} + \sqrt{5}}$.
A: $\dfrac{\sqrt{7} - \sqrt{5}}{2}$.

Q: If $x = 3 - 2\sqrt{2}$, find $x + \dfrac{1}{x}$ and $x^2 + \dfrac{1}{x^2}$.
A: 6 and 34.

Q: Simplify $\sqrt{12} + \sqrt{27} - \sqrt{48}$.
A: $\sqrt{3}$.

Q: Find the value of $(2 + \sqrt{3})(2 - \sqrt{3})$.
A: 1.

Q: Is the number 0.101001000100001... (the number of zeroes grows each time) rational or irrational?
A: Irrational, because the decimal neither terminates nor repeats.
