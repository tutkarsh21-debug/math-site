# Solved HOTS questions
- Basics: $\sin^2\theta + \cos^2\theta = 1$, $1 + \tan^2\theta = \sec^2\theta$, $1 + \cot^2\theta = \text{cosec}^2\theta$, and $\sin(90^\circ - \theta) = \cos\theta$. When one ratio is given, draw a right triangle, find the third side by Pythagoras and read off every ratio.
?eg If $\tan\theta = \dfrac{4}{3}$, find the value of $\dfrac{3\sin\theta + 2\cos\theta}{3\sin\theta - 2\cos\theta}$.
= Take a right triangle with opposite side 4, adjacent side 3 and hypotenuse 5. So $\sin\theta = \dfrac{4}{5}$ and $\cos\theta = \dfrac{3}{5}$.
= Numerator $= \dfrac{12}{5} + \dfrac{6}{5} = \dfrac{18}{5}$. Denominator $= \dfrac{12}{5} - \dfrac{6}{5} = \dfrac{6}{5}$.
=> 3
?eg Show that $(1 + \tan^2\theta)(1 - \sin\theta)(1 + \sin\theta) = 1$.
= $(1 - \sin\theta)(1 + \sin\theta) = 1 - \sin^2\theta = \cos^2\theta$.
= $1 + \tan^2\theta = \sec^2\theta = \dfrac{1}{\cos^2\theta}$.
= The product is $\dfrac{1}{\cos^2\theta} \times \cos^2\theta$.
=> 1
?eg If $\sin\theta + \cos\theta = \dfrac{7}{5}$, find $\tan\theta + \cot\theta$.
= Square both sides: $1 + 2\sin\theta\cos\theta = \dfrac{49}{25}$, so $\sin\theta\cos\theta = \dfrac{12}{25}$.
= $\tan\theta + \cot\theta = \dfrac{\sin^2\theta + \cos^2\theta}{\sin\theta\cos\theta} = \dfrac{1}{12/25}$.
=> $\dfrac{25}{12}$
?eg If $\sec\theta + \tan\theta = 3$, find $\sin\theta$.
= $(\sec\theta + \tan\theta)(\sec\theta - \tan\theta) = \sec^2\theta - \tan^2\theta = 1$, so $\sec\theta - \tan\theta = \dfrac{1}{3}$.
= Adding: $2\sec\theta = \dfrac{10}{3}$, so $\sec\theta = \dfrac{5}{3}$. Subtracting: $\tan\theta = \dfrac{4}{3}$.
= $\sin\theta = \tan\theta \times \cos\theta = \dfrac{4}{3} \times \dfrac{3}{5}$.
=> $\dfrac{4}{5}$
?eg Evaluate $\sin 25^\circ \cos 65^\circ + \cos 25^\circ \sin 65^\circ$.
= $\sin 25^\circ = \cos 65^\circ$ and $\cos 25^\circ = \sin 65^\circ$, because $25^\circ + 65^\circ = 90^\circ$.
= The expression is $\cos^2 65^\circ + \sin^2 65^\circ$.
=> 1

@@dpp
Q: If $\tan\theta = \dfrac{5}{12}$, find $\sin\theta + \cos\theta$.
A: $\dfrac{17}{13}$.

Q: Show that $(1 - \cos^2\theta)(1 + \cot^2\theta) = 1$.
A: $\sin^2\theta \times \text{cosec}^2\theta = 1$.

Q: If $\sin\theta - \cos\theta = \dfrac{1}{5}$, find $\sin\theta\cos\theta$.
A: $\dfrac{12}{25}$.

Q: If $\sec\theta + \tan\theta = 2$, find $\sin\theta$.
A: $\dfrac{3}{5}$.

Q: Evaluate $\tan 10^\circ \tan 20^\circ \tan 70^\circ \tan 80^\circ$.
A: 1 (since $\tan 10^\circ \tan 80^\circ = 1$ and $\tan 20^\circ \tan 70^\circ = 1$).

Q: Simplify $\dfrac{\sin\theta}{1 + \cos\theta} + \dfrac{1 + \cos\theta}{\sin\theta}$.
A: $2\,\text{cosec}\,\theta$.

Q: Evaluate $\sin 30^\circ \cos 60^\circ + \cos 30^\circ \sin 60^\circ$.
A: 1.

Q: If $\cos\theta = \dfrac{8}{17}$, find the value of $\dfrac{1 - \tan^2\theta}{1 + \tan^2\theta}$.
A: $-\dfrac{161}{289}$ (this equals $2\cos^2\theta - 1$).
