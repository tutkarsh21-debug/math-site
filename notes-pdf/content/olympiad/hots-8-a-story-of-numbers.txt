# Solved HOTS questions
- In the decimal (base 10) system each place is worth 10 times the place to its right. In base $b$ the places are worth $1, b, b^2, b^3, \ldots$. Writing a number in a new base is repeated division by the base, reading the remainders from the last to the first.
?eg Write 1000 in base 5.
= $1000 \div 5 = 200$ remainder 0; $200 \div 5 = 40$ remainder 0; $40 \div 5 = 8$ remainder 0; $8 \div 5 = 1$ remainder 3; $1 \div 5 = 0$ remainder 1.
= Reading the remainders from the last to the first: 1 3 0 0 0.
=> $13000_5$
?eg Find the value of $2314_5$ in base 10.
= $2 \times 5^3 + 3 \times 5^2 + 1 \times 5 + 4 = 250 + 75 + 5 + 4$.
=> 334
?eg Write the number 40 506 070 in words in the Indian system, and give the place value of the digit 5.
= In the Indian system the digits are grouped as 4,05,06,070 (the last three digits, then groups of two).
= So the number is 4 crore, 5 lakh, 6 thousand and 70. The digit 5 is in the lakh place, so its value is 5 lakh $= 500\,000$.
=> Four crore five lakh six thousand seventy; the digit 5 stands for 500 000
?eg A number in base 2 is 1011. Write it in base 10 and add 1 to it in base 2.
= $1 \times 8 + 0 \times 4 + 1 \times 2 + 1 = 11$.
= Adding 1 in base 2: $1011 + 1 = 1100$, which is 12.
=> 11, and $1100_2$
?eg Why is zero important in a place-value system?
= Zero holds an empty place. Without it 105 and 15 could not be told apart, and 100 would look like 1.
= It also lets a few digits write any number.
=> Zero marks an empty place, so the position of every digit has a clear meaning

Q: Write 100 in base 2.
A: $1100100_2$.

Q: Find the value of $1342_5$ in base 10.
A: 222 ($125 + 75 + 20 + 2$).

Q: Write 4 05 06 070 in the Indian system in words and give the value of the digit 6.
A: Four crore five lakh six thousand seventy. The digit 6 stands for 6000.

Q: Write the number 25 in base 2.
A: $11001_2$.

Q: Add $1101_2$ and $11_2$ and give the answer in base 2.
A: $10000_2$ ($13 + 3 = 16$).

Q: In which place is the digit 7 of 7 654 321 in the international system, and what is its value?
A: The millions place, and its value is 7 000 000.

Q: What is the largest digit that can be used in base 6?
A: 5.

Q: How many different numbers can be written with 3 binary digits (0 and 1 only, leading zeros allowed)?
A: 8 (from 000 to 111).
