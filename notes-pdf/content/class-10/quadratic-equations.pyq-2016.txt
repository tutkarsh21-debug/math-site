T: Solving by factorisation
Q: [CBSE 2016, 3 marks] Solve for $x$: $\dfrac{1}{(x - 1)(x - 2)} + \dfrac{1}{(x - 2)(x - 3)} = \dfrac{2}{3}$, where $x \neq 1, 2, 3$.
S: LHS $= \dfrac{(x - 3) + (x - 1)}{(x - 1)(x - 2)(x - 3)} = \dfrac{2(x - 2)}{(x - 1)(x - 2)(x - 3)} = \dfrac{2}{(x - 1)(x - 3)}$
S: $\dfrac{2}{(x - 1)(x - 3)} = \dfrac{2}{3}$, so $(x - 1)(x - 3) = 3$
S: $x^2 - 4x + 3 = 3$, so $x(x - 4) = 0$
S: **Answer: $x = 0$ or $x = 4$**

T: Solving by the quadratic formula
Q: [CBSE 2016, 4 marks] Solve for $x$: $\dfrac{1}{x + 1} + \dfrac{2}{x + 2} = \dfrac{4}{x + 4}$, where $x \neq -1, -2, -4$.
S: LHS $= \dfrac{(x + 2) + 2(x + 1)}{(x + 1)(x + 2)} = \dfrac{3x + 4}{x^2 + 3x + 2}$
S: $(3x + 4)(x + 4) = 4(x^2 + 3x + 2)$, so $3x^2 + 16x + 16 = 4x^2 + 12x + 8$
S: $x^2 - 4x - 8 = 0$. Here $D = 16 + 32 = 48$.
S: $x = \dfrac{4 \pm \sqrt{48}}{2} = \dfrac{4 \pm 4\sqrt{3}}{2}$
S: **Answer: $x = 2 + 2\sqrt{3}$ or $x = 2 - 2\sqrt{3}$**

T: Nature of roots
Q: [CBSE 2016, 2 marks] $-5$ is a root of $2x^2 + px - 15 = 0$, and the equation $p(x^2 + x) + k = 0$ has equal roots. Find $k$.
S: Put $x = -5$ in the first equation: $50 - 5p - 15 = 0$, so $p = 7$.
S: The second equation is $7x^2 + 7x + k = 0$. Equal roots need $D = 0$: $49 - 28k = 0$.
S: **Answer: $k = \dfrac{7}{4}$**

T: Word problems
Q: [CBSE 2016, 4 marks] A motor boat has a speed of 24 km/h in still water. It takes 1 hour longer to go 32 km upstream than to return the same distance downstream. Find the speed of the stream.
S: Let the speed of the stream be $x$ km/h.
S: $\dfrac{32}{24 - x} - \dfrac{32}{24 + x} = 1$
S: $32(24 + x) - 32(24 - x) = 576 - x^2$, so $64x = 576 - x^2$ and $x^2 + 64x - 576 = 0$
S: $(x + 72)(x - 8) = 0$, so $x = 8$.
S: **Answer: 8 km/h**
