T: Solution set and the replacement set
Q: [ICSE 2025, 1 mark] Find the solution set of $0 < -\dfrac{x}{3} < 2$, $x \in Z$. (a) $\{-5, -4, -3, -2, -1\}$  (b) $\{-6, -5, -4, -3, -2, -1\}$  (c) $\{-5, -4, -3, -2, -1, 0\}$  (d) $\{-6, -5, -4, -3, -2, -1, 0\}$
S: Multiply through by $-3$. Multiplying by a negative number reverses the signs: $0 > x > -6$.
S: The integers between $-6$ and 0 (both excluded) are $-5, -4, -3, -2, -1$.
S: **Answer: (a)**

T: Combining inequations
Q: [ICSE 2025, 3 marks] Solve $2x - \dfrac{5}{3} < \dfrac{3x}{5} + 10 \leq \dfrac{4x}{5} + 11$, $x \in R$. Write the solution set and show it on the number line.
S: Left part: $2x - \dfrac{3x}{5} < 10 + \dfrac{5}{3}$, so $\dfrac{7x}{5} < \dfrac{35}{3}$ and $x < \dfrac{25}{3}$.
S: Right part: $10 - 11 \leq \dfrac{4x}{5} - \dfrac{3x}{5}$, so $-1 \leq \dfrac{x}{5}$ and $x \geq -5$.
S: **Solution set: $\left\{x : -5 \leq x < 8\dfrac{1}{3},\ x \in R\right\}$**
