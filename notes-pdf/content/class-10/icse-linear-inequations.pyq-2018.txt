T: Combining inequations
Q: [ICSE 2018, 3 marks] Solve $-2 + 10x \leq 13x + 10 < 24 + 10x$, where $x$ is an integer. Write the solution set and show it on the number line.
S: Left part: $-12 \leq 3x$, so $x \geq -4$.
S: Right part: $3x < 14$, so $x < 4\dfrac{2}{3}$.
S: **Solution set: $\{-4, -3, -2, -1, 0, 1, 2, 3, 4\}$**
