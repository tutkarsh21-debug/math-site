T: Combining inequations
Q: [ICSE 2019, 3 marks] Solve $11x - 4 < 15x + 4 \leq 13x + 14$, where $x$ is a whole number. Write the solution set and show it on the number line.
S: Left part: $-8 < 4x$, so $x > -2$.
S: Right part: $2x \leq 10$, so $x \leq 5$.
S: The whole numbers with $-2 < x \leq 5$ are 0, 1, 2, 3, 4, 5.
S: **Solution set: $\{0, 1, 2, 3, 4, 5\}$**
