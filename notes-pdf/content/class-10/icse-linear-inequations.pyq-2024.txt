T: Combining inequations
Q: [ICSE 2024, 3 marks] Solve $-3 + x \leq \dfrac{7x}{2} + 2 < 8 + 2x$, where $x$ is an integer. Write the solution set and show it on the number line.
S: Left part: $-3 - 2 \leq \dfrac{7x}{2} - x$, so $-5 \leq \dfrac{5x}{2}$ and $x \geq -2$.
S: Right part: $\dfrac{7x}{2} - 2x < 8 - 2$, so $\dfrac{3x}{2} < 6$ and $x < 4$.
S: **Solution set: $\{-2, -1, 0, 1, 2, 3\}$**
