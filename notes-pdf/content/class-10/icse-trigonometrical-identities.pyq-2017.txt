T: Proving identities
Q: [ICSE 2017, 3 marks] Prove that $\dfrac{\sin\theta - 2\sin^3\theta}{2\cos^3\theta - \cos\theta} = \tan\theta$.
S: LHS $= \dfrac{\sin\theta(1 - 2\sin^2\theta)}{\cos\theta(2\cos^2\theta - 1)}$
S: Using $1 = \sin^2\theta + \cos^2\theta$: $1 - 2\sin^2\theta = \cos^2\theta - \sin^2\theta$ and $2\cos^2\theta - 1 = \cos^2\theta - \sin^2\theta$.
S: The brackets cancel: LHS $= \dfrac{\sin\theta}{\cos\theta} = \tan\theta$ = RHS. **Proved.**

T: Complementary angles
Q: [ICSE 2017, 3 marks] Without using tables, evaluate $\sin^2 28° + \sin^2 62° + \tan^2 38° - \cot^2 52° + \dfrac{1}{4}\sec^2 30°$.
S: $\sin 62° = \cos 28°$, so $\sin^2 28° + \sin^2 62° = \sin^2 28° + \cos^2 28° = 1$.
S: $\cot 52° = \tan 38°$, so $\tan^2 38° - \cot^2 52° = 0$.
S: $\dfrac{1}{4}\sec^2 30° = \dfrac{1}{4} \times \dfrac{4}{3} = \dfrac{1}{3}$
S: **Answer: $1 + 0 + \dfrac{1}{3} = \dfrac{4}{3}$**
