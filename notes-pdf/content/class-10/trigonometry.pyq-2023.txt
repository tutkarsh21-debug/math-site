T: Trigonometric ratios
Q: [CBSE 2023, 1 mark] If $2\tan A = 3$, find the value of $\dfrac{4\sin A + 3\cos A}{4\sin A - 3\cos A}$. (a) $\dfrac{7}{\sqrt{13}}$  (b) $\dfrac{1}{\sqrt{13}}$  (c) 3  (d) does not exist
S: Divide the numerator and the denominator by $\cos A$: $\dfrac{4\tan A + 3}{4\tan A - 3}$
S: $\tan A = \dfrac{3}{2}$, so $4\tan A = 6$ and the value is $\dfrac{6 + 3}{6 - 3} = 3$.
S: **Answer: (c)**
Q: [CBSE 2023, 2 marks] If $\sin\alpha = \dfrac{1}{\sqrt{2}}$ and $\cot\beta = \sqrt{3}$, find $\mathrm{cosec}\,\alpha + \mathrm{cosec}\,\beta$.
S: $\mathrm{cosec}\,\alpha = \dfrac{1}{\sin\alpha} = \sqrt{2}$
S: $\cot\beta = \sqrt{3}$ gives $\beta = 30°$, so $\mathrm{cosec}\,\beta = 2$.
S: **Answer: $2 + \sqrt{2}$**

T: Ratios of standard angles
Q: [CBSE 2023, 1 mark] Evaluate $\dfrac{3}{4}\tan^2 30° - \sec^2 45° + \sin^2 60°$. (a) $-1$  (b) $\dfrac{5}{6}$  (c) $-\dfrac{3}{2}$  (d) $\dfrac{1}{6}$
S: $\tan^2 30° = \dfrac{1}{3}$, $\sec^2 45° = 2$ and $\sin^2 60° = \dfrac{3}{4}$
S: Value $= \dfrac{3}{4} \times \dfrac{1}{3} - 2 + \dfrac{3}{4} = \dfrac{1}{4} - 2 + \dfrac{3}{4} = -1$
S: **Answer: (a)**

T: Trigonometric identities
Q: [CBSE 2023, 2 marks] If $\sin\theta + \cos\theta = \sqrt{3}$, find the value of $\sin\theta\cos\theta$.
S: Square both sides: $\sin^2\theta + \cos^2\theta + 2\sin\theta\cos\theta = 3$
S: $1 + 2\sin\theta\cos\theta = 3$
S: **Answer: $\sin\theta\cos\theta = 1$**
Q: [CBSE 2023, 3 marks] Prove that $\dfrac{\tan\theta + \sec\theta - 1}{\tan\theta - \sec\theta + 1} = \dfrac{1 + \sin\theta}{\cos\theta}$.
S: In the numerator, replace 1 by $\sec^2\theta - \tan^2\theta$.
S: Numerator $= (\sec\theta + \tan\theta) - (\sec\theta + \tan\theta)(\sec\theta - \tan\theta) = (\sec\theta + \tan\theta)(1 - \sec\theta + \tan\theta)$
S: The second bracket is the same as the denominator, so LHS $= \sec\theta + \tan\theta$.
S: $= \dfrac{1}{\cos\theta} + \dfrac{\sin\theta}{\cos\theta} = \dfrac{1 + \sin\theta}{\cos\theta}$ = RHS. **Proved.**
