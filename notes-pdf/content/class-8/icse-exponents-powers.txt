# Powers
- $a^n$ means $a$ multiplied by itself $n$ times. $a$ is the **base** and $n$ is the **exponent** (index or power).
- $a^1 = a$. **Zero exponent**: $a^0 = 1$ for every $a \neq 0$.
- **Negative exponent**: $a^{-n} = \dfrac{1}{a^n}$ and $\dfrac{1}{a^{-n}} = a^n$.
- For a fraction: $\left(\dfrac{a}{b}\right)^{-n} = \left(\dfrac{b}{a}\right)^n$.
- A negative base with an **even** exponent gives a positive result; with an **odd** exponent, a negative result.
?eg Evaluate $(-3)^4$, $(-2)^5$, $7^0$ and $4^{-3}$.
=> 81, $-32$, 1 and $\dfrac{1}{64}$
?eg Evaluate $\left(\dfrac{2}{3}\right)^{-3}$.
= $\left(\dfrac{3}{2}\right)^3$
=> $\dfrac{27}{8}$

# Laws of exponents
- For non-zero bases $a$, $b$ and integers $m$, $n$:
| Law | Statement |
| Product | $a^m \times a^n = a^{m+n}$ |
| Quotient | $a^m \div a^n = a^{m-n}$ |
| Power of a power | $(a^m)^n = a^{mn}$ |
| Power of a product | $(ab)^n = a^n \times b^n$ |
| Power of a quotient | $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$ |
- The product and quotient laws need the **same base**.
- If $a^m = a^n$ and $a$ is not $0$, $1$ or $-1$, then $m = n$.
?eg Simplify $2^5 \times 2^{-8} \times 2^6$.
= $2^{5 - 8 + 6}$
=> $2^3 = 8$
?eg Simplify $\left(\dfrac{3}{4}\right)^{5} \div \left(\dfrac{3}{4}\right)^{3}$.
= $\left(\dfrac{3}{4}\right)^2$
=> $\dfrac{9}{16}$
?eg Simplify $\dfrac{(5^2)^3 \times 5^4}{5^7}$.
= $5^{6 + 4 - 7}$
=> $5^3 = 125$
?eg Simplify $(2^{-1} + 3^{-1})^{-1}$.
= $\left(\dfrac{1}{2} + \dfrac{1}{3}\right)^{-1} = \left(\dfrac{5}{6}\right)^{-1}$
=> $\dfrac{6}{5}$
?eg Simplify $\left(\dfrac{1}{3}\right)^{-2} - \left(\dfrac{1}{2}\right)^{-3} + 4^0$.
= $9 - 8 + 1$
=> 2

# Fractional exponents
- $a^{\frac{1}{2}} = \sqrt{a}$ and $a^{\frac{1}{3}} = \sqrt[3]{a}$. In general $a^{\frac{1}{n}} = \sqrt[n]{a}$.
- $a^{\frac{m}{n}} = \left(\sqrt[n]{a}\right)^m$: take the root first, then the power.
- The laws of exponents hold for fractional exponents too.
?eg Evaluate $(64)^{\frac{2}{3}}$ and $(81)^{\frac{3}{4}}$.
= $(4^3)^{\frac{2}{3}} = 4^2$ and $(3^4)^{\frac{3}{4}} = 3^3$
=> 16 and 27
?eg Evaluate $\left(\dfrac{27}{125}\right)^{-\frac{2}{3}}$.
= $\left(\dfrac{125}{27}\right)^{\frac{2}{3}} = \left(\dfrac{5}{3}\right)^2$
=> $\dfrac{25}{9}$

# Expressing in exponential form
- Write the number as a product of prime factors and collect equal factors.
?eg Express 432 as a product of powers of primes.
=> $2^4 \times 3^3$
?eg Simplify $\dfrac{16 \times 2^{n+1} - 4 \times 2^n}{16 \times 2^{n+2} - 2 \times 2^{n+2}}$.
= Numerator: $2^n(32 - 4) = 28 \times 2^n$. Denominator: $2^n(64 - 8) = 56 \times 2^n$.
=> $\dfrac{1}{2}$

# Finding an unknown exponent
- Make the bases equal on both sides, then equate the exponents.
?eg Find $x$ if $3^{x+1} = 81$.
= $3^{x+1} = 3^4$
=> $x = 3$
?eg Find $x$ if $\left(\dfrac{2}{5}\right)^{3} \times \left(\dfrac{2}{5}\right)^{-6} = \left(\dfrac{2}{5}\right)^{2x-1}$.
= $3 - 6 = 2x - 1$
=> $x = -1$
?eg Find $x$ if $4^{x} = 8^{x-1}$.
= $2^{2x} = 2^{3x - 3}$, so $2x = 3x - 3$
=> $x = 3$
?eg By what number should $(-8)^{-1}$ be multiplied to get $10^{-1}$?
= Required number $= \dfrac{1}{10} \div \dfrac{-1}{8} = \dfrac{1}{10} \times (-8)$
=> $-\dfrac{4}{5}$

# Standard form
- A number in **standard form** is written as $k \times 10^n$, where $1 \leq k < 10$ and $n$ is an integer.
- Large numbers have positive $n$; small numbers (less than 1) have negative $n$.
?eg Write 3,84,000 and 0.00056 in standard form.
=> $3.84 \times 10^5$ and $5.6 \times 10^{-4}$
?eg Write $2.07 \times 10^{-3}$ in the usual form.
=> 0.00207

# Common mistakes
- Writing $2^3 = 6$. It is $2 \times 2 \times 2 = 8$.
- Taking $a^{-n}$ as a negative number.
- Writing $a^0 = 0$.
- Adding exponents with different bases, or multiplying exponents where they should be added.
- Writing $(a + b)^n = a^n + b^n$.
- Confusing $(-2)^4 = 16$ with $-2^4 = -16$.
