# Inequations
- An **inequation** compares two expressions with one of the signs $<$, $>$, $\leq$, $\geq$.
| Sign | Read as |
| $<$ | is less than |
| $>$ | is greater than |
| $\leq$ | is less than or equal to |
| $\geq$ | is greater than or equal to |
- A **linear inequation in one variable** has the form $ax + b < c$ (or with $>$, $\leq$, $\geq$), where $a \neq 0$.
- $x < 5$ and $5 > x$ mean the same thing.

# Replacement set and solution set
- The **replacement set** (domain) is the set from which values of the variable are chosen. It is given in the question.
- The **solution set** is the set of all values from the replacement set that satisfy the inequation.
- The same inequation can have different solution sets for different replacement sets.
| Symbol | Set | Elements |
| $N$ | Natural numbers | $1, 2, 3, \ldots$ |
| $W$ | Whole numbers | $0, 1, 2, 3, \ldots$ |
| $Z$ or $I$ | Integers | $\ldots, -2, -1, 0, 1, 2, \ldots$ |
| $R$ | Real numbers | All points on the number line |
?eg Write the solution set of $x < 4$ when the replacement set is (i) $N$ (ii) $W$ (iii) $\{-2, 0, 3, 5, 6\}$.
=> (i) $\{1, 2, 3\}$ (ii) $\{0, 1, 2, 3\}$ (iii) $\{-2, 0, 3\}$

# Rules for solving
- **Adding or subtracting** the same number on both sides does **not** change the sign.
- **Multiplying or dividing** both sides by the same **positive** number does **not** change the sign.
- **Multiplying or dividing** both sides by the same **negative** number **reverses** the sign: $<$ becomes $>$ and $\leq$ becomes $\geq$.
- A term may be transposed from one side to the other by changing its sign, just as in an equation.
- If the sides are interchanged, the sign reverses: $a > b$ is the same as $b < a$.
?eg Solve $3x - 5 < 10$, $x \in N$.
= $3x < 15$, so $x < 5$
=> $\{1, 2, 3, 4\}$
?eg Solve $-2x \geq 6$, $x \in Z$.
= Divide by $-2$ and reverse the sign: $x \leq -3$.
=> $\{\ldots, -5, -4, -3\}$
?eg Solve $7 - 3x > 1$, $x \in W$.
= $-3x > -6$, so $x < 2$
=> $\{0, 1\}$
?eg Solve $5x + 2 \leq 3x + 12$, $x \in N$.
= $2x \leq 10$, so $x \leq 5$
=> $\{1, 2, 3, 4, 5\}$
?eg Solve $\dfrac{2x - 1}{3} > 3$, $x \in \{1, 2, 3, \ldots, 8\}$.
= $2x - 1 > 9$, so $x > 5$
=> $\{6, 7, 8\}$
?eg Solve $\dfrac{x}{2} - \dfrac{x}{3} \leq 1$, $x \in W$.
= Multiply by 6: $3x - 2x \leq 6$
=> $\{0, 1, 2, 3, 4, 5, 6\}$

# On the number line
- For a solution set of **integers, whole or natural numbers**: mark each solution with a thick dot. Three dots beyond the last marked number show that the set continues.
- For **real numbers**: draw a thick line over the part that is included. Use a **solid dot** at an end point that is included ($\leq$ or $\geq$) and a **hollow circle** at an end point that is not included ($<$ or $>$).

# Combined inequations
- A statement such as $-3 < 2x - 1 \leq 5$ contains two inequations. Solve by doing the same operation to **all three parts**.
- Or split it into two inequations, solve each, and take the values common to both.
?eg Solve $-3 < 2x - 1 \leq 5$, $x \in Z$.
= Add 1: $-2 < 2x \leq 6$. Divide by 2: $-1 < x \leq 3$.
=> $\{0, 1, 2, 3\}$
?eg Solve $-5 \leq 3x + 1 < 10$, $x \in R$, and describe the graph.
= Subtract 1: $-6 \leq 3x < 9$. Divide by 3: $-2 \leq x < 3$.
=> All real numbers from $-2$ to 3; solid dot at $-2$, hollow circle at 3
?eg Solve $2 \leq 5 - x < 6$, $x \in Z$.
= Subtract 5: $-3 \leq -x < 1$. Multiply by $-1$ and reverse: $3 \geq x > -1$.
=> $\{0, 1, 2, 3\}$

# Greatest and least values
?eg Find the greatest value of $x$ satisfying $4x - 3 \leq 17$, $x \in N$, and the least value of $x$ satisfying $2x + 1 > 9$, $x \in N$.
= $x \leq 5$; and $x > 4$
=> Greatest 5; least 5
?eg Find the smallest integer satisfying $3x + 8 > 2$.
= $3x > -6$, so $x > -2$
=> $-1$

# Common mistakes
- Not reversing the sign when multiplying or dividing by a negative number.
- Reversing the sign when adding or subtracting, or when dividing by a positive number.
- Ignoring the replacement set and listing numbers that are not in it.
- Including an end point when the sign is $<$ or $>$.
- Using a solid dot where a hollow circle is needed.
- Listing 0 as a natural number.

@@formulas
Add or subtract | Sign unchanged
Multiply or divide by a positive number | Sign unchanged
Multiply or divide by a negative number | Sign reversed
Interchange sides | $a > b$ means $b < a$
Replacement set | The set from which values of $x$ are taken
Solution set | Values in the replacement set that satisfy the inequation
Natural numbers | $N = \{1, 2, 3, \ldots\}$
Whole numbers | $W = \{0, 1, 2, \ldots\}$
Integers | $Z = \{\ldots, -1, 0, 1, \ldots\}$
Included end point | $\leq$ or $\geq$: solid dot
Excluded end point | $<$ or $>$: hollow circle
Combined inequation | Do the same operation to all three parts
